# <img src="assets/orbit-logo.svg" alt="" width="48" height="48" align="center"> Orbite

**拯救反重力，让它像 Codex 一样好用。**

Antigravity 能干活，坐在它前面的人不该跟着费劲。拖一个文件夹进去、同时跑两条任务、看一眼它到底改了什么，这些事本来就该顺手。Orbite 是为此做的独立 macOS 客户端。

拿 Codex 当好用的标杆，借一点 Claude Code 的操作记录和 Metro 的转场。账号、模型和执行仍然走 Google Antigravity；不用 OpenAI 或 Anthropic 账号，也不解锁 Codex 权益。Orbite 不是 Google 官方产品。

## 现在能做什么

- **文件直接拖进去。** 从 Finder 拖文件或文件夹，也可以点「＋」选取。发之前能看到加了什么，原件不动。
- **任务分开跑。** 在不同项目间来回切，或用独立 Git 工作树隔离改动。想给运行中的任务补一句话，不用先停掉它。
- **改了什么，一眼能查。** 对话里可展开工具操作，审阅面板逐文件看 Git diff；需要时可以导出已跟踪改动的补丁。

## 想一起把什么做顺

1. **Computer Use**：把权限提示、驱动自测、真实 Antigravity 会话联调跑通。目前是可选的 Cua Driver 接入，还没有完成实机验收。
2. **Mac 安装包**：现在是 Electron 源码开发版。下一步是把安装、启动和升级做成普通 Mac 用户也能走通的流程。
3. **工作树与审阅**：让改动更好拿回来，补安全合并、行级审阅和更完整的附件体验。

遇到卡手的地方，欢迎[开 Issue](https://github.com/Rseam-07/orbite/issues)说说你在做什么、卡在哪一步。想直接改代码，看[贡献指南](CONTRIBUTING.md)；想挑功能，看[与 Codex 的逐项对照](对照与后续.md)。

## 先试界面

在仓库目录运行 `node build-preview.cjs`，双击生成的 **Orbite-Preview.html**。会先进入项目列表。点 Atelier，会话页面从项目图标所在位置侧转展开；再点「审阅」看面板滑入，对话仍在同一画面。

也可以新建会话、搜索、选取或拖入文件夹，再看审批如何出现。设置里可以选择浅色、深色或跟随系统，也能关闭「玻璃质感」；系统开启「减少动态效果」后将跳过位移转场。预览中的项目、文件补丁、模型回复均为示例，不会联网、不执行命令、不读附件内容。

## 在 Mac 上运行

从旧版 Orbit 更新时，客户端沿用原有的本地数据目录，不需要手动搬文件。

1. 安装 Node.js 22+ 和[官方 Antigravity CLI](https://antigravity.google/docs/cli-install)。终端运行 `agy --version` 可确认安装。
2. 在仓库目录运行 `npm ci`，再运行 `npm start`。
3. 选择信任的项目，直接输入消息。Orbite 会连接 `agy acp --sandbox`。已在 CLI 登录时，通常可复用 Google 会话；未登录时，在连接提示中选择 Google 登录，认证由官方 CLI 在默认浏览器完成。若当前版本未暴露此入口，先在终端运行 `agy` 登录。Orbite 不收集密码和令牌。
4. 最新 CLI 支持哪些模型、推理等级和会话模式，以下方实际出现的控件为准。切换会话会重建连接；历史保存在本机，重新启动后的首次运行需要重新选择原项目。不同目录的会话可同时运行；同一目录的第二条会话会被拦下。原有工作副本和独立工作树不共用目录。

### 并行与独立工作树

- 一个会话执行时，可以切到另一项目或会话。侧栏标示「运行中」和「待审批」。当前会话的圆形停止键只停止该回合，不动其它会话。
- 新建会话前，用输入区下方的「项目目录 / 独立工作树」切换。工作树从仓库当前 `HEAD` 创建自己的 `orbit/…` 本地分支，**不复制原目录中的未提交改动、未跟踪文件、依赖或本地配置**。项目需有至少一个 Git 提交；请打开仓库根目录。不同工作树可以并行。Orbite 不自动提交、合并、推送或删除工作树；如果要取回文件，可点输入区下方「显示工作树目录」在访达定位。
- 任务运行中输入纯文字并点击发送，即向当前 Antigravity 会话补充指令；停止是另一按钮。一次只发送一条补充。若当前 CLI 不接受追加，错误会显示，文本回到草稿，不会自动再发。带附件请等到下一回合。
- 与 `agy` 建立会话后，键入 `/` 可以浏览该会话广播的命令。没有广播时仍可手动输入；Orbite 不会自动安装任何 Skill。

### 文件、变更与审批

- 从访达拖入，或点输入框左下角「＋」选择文件/文件夹。发送前可以检查名称、大小和移除附件。切换会话不会混用附件草稿。
- 发送时会复制到项目下的 `.orbit-attachments`，**不改动原件**。每回合最多 16 个顶层附件、64 MiB 合计、1,000 个条目。常见凭据、符号链接、依赖与版本库目录会跳过。这不是完整的凭据扫描，不要添加不愿交给模型处理的内容。不要将附件副本提交到 Git。
- 在输入框按 ⌘V 可贴入截图（PNG、JPEG、WebP，单张最多 16 MiB）。图片先留在本次打开的会话草稿里，不会自动发送。普通文字粘贴保持原样。发送时复用附件流程；超出 8 MiB 内联预算或不支持图片输入时，会作为工作区文件发送。
- 支持的图片走 ACP 图片输入；文件及目录作为工作区资料交给 Antigravity 读取。没有独立云盘、Office 内置预览或自动导出。
- 审阅可以展开或关闭；可按文件看 Git 补丁，并把文件名引用带回输入框。审阅可切换「工作区状态」和「本会话工具变更」。前者在工作树中以创建时的提交为基线，包含后续本地提交；后者只包括当前进程收到的 ACP 文件变更事件，不把已有改动或没有发送事件的命令归给模型。操作请求在当前对话中显示，插件工具调用状态也从 ACP 进入活动记录。Orbite 不自动批准权限、不提交或回滚代码。引擎或插件自身的既有权限规则仍有效。

### Computer Use：在 Mac 上验到哪一步

参考图里的原版叫 **Computer Use**，二进制名为 `antigravity-cua`；未核实到其公开下载。本版采用 [Cua Driver 的 Antigravity MCP](https://cua.ai/docs/cua-driver/guides/gemini)，不捆绑或替换 Codex 私有组件。

1. 在 **Mac 本机**按 [Cua Driver 官方安装说明](https://cua.ai/docs/cua-driver/quickstart) 安装驱动。Orbite 不自动下载执行安装器。
2. 打开 Orbite 的「扩展 → 检测本机」。Orbite 查找安装的驱动，进行真实的 MCP 握手、列出工具，并从驱动读取辅助功能/录屏状态。检测本身不会截屏，也不会要求授权。自动找不到时可选取 `cua-driver`。
3. 需要权限时点「打开授权流程」，按 macOS 指引在系统设置确认。授权给谁以驱动报告和系统提示为准；新权限可能要重启 CuaDriver。完成后再次检测。
4. 两项权限都开启后，点「运行官方自测」。它调用 `cua-driver test --json`，由驱动实际检查屏幕并在后台 TextEdit 测试输入，不保存文稿。只有通过，面板才会显示「自测通过」。这个自测不需要 Google 账户，但它成功不意味着 Antigravity 已连接。
5. 打开项目，勾选「将 Cua Driver 接到当前会话」，点「填入只读联调指令」，再自行发送。它要求 Antigravity 仅调用 `check_permissions`（`prompt:false`）。在「审阅 → 活动」确认确实出现了对应工具的完成事件，**不要只把模型的文字当作成功证据**。如果驱动自测成功但没有工具事件，先核对本机 `agy` 版本与 [Google ACP 文档](https://antigravity.google/docs/ide/extensions/acp/)；也可以选择按 Cua Driver 文档的官方全局接入方式配置，但 Orbite 不替你改全局设置。

会话启用默认关闭，切换到其它会话不会自动继承。每次只允许一个由 Orbite 明确启用桌面控制的回合运行。驱动或 CLI 已存在的全局权限、MCP 和可见应用不归 Orbite 的开关管理。后台动作并非每种窗口都能完成，不保证与 Codex 同样的工具面和权限行为。

## 0.7 的界面

- 用暖灰背景、单一灰绿色强调色和分隔线替换大标题、背景纹样及大色块。首页以项目路径、最近会话和运行状态为主。保留 Metro 的方形项目入口和原来的翻页逻辑，图标是转场锚点。
- 会话是按阅读顺序展开的操作记录。引擎报告的工具步骤在对话内收起为「N 项操作」，可展开查看状态。每轮保留最近 20 条工具摘要，与会话一同保存在本地；工作区审阅仍是独立面板。交互参考 [Claude Code Desktop](https://code.claude.com/docs/en/desktop) 和 [Claude Code 的终端更新](https://www.anthropic.com/news/enabling-claude-code-to-work-more-autonomously)，不连接 Anthropic。
- 毛玻璃仅用于窗口边缘与浮层，可在设置里关掉。切换页面时不会对静止内容以外的背景做实时模糊。

- ACP 传输独立为模块：正确拼接分段 UTF-8，限制单条消息大小；非法消息、断管、超时和进程退出会清理挂起的请求。
- 停止后如果引擎没有应答，Orbite 断开这一会话，不关闭其它任务；已产生的文件修改不会被撤销。中途断线会保留部分回复并标注结果未确认，不自动重发。
- 流式回复按帧更新；读以前的消息时，不强行滚到最新回复。审阅阻止晚回来的旧请求覆盖最新结果。快速切换项目时只采纳最后一次导航。
- 启动动作参考 [微软 BUILD 2011 原片](https://learn.microsoft.com/en-us/shows/build-build2011/app-206t) 5:06–5:08：当前工作台保留在后面，实际会话页面侧转展开，不使用整页截图、磁贴残影或逐帧布局。连点时中止并清理上一个转场，不把完成的 3D 变换留在内容上。输入区、侧栏、工具栏、静止审阅区用毛玻璃；翻页或侧板移动时停用其动态背景模糊。
- 独立工作树可导出相对起点的 Git 补丁。只读导出，不执行提交、合并或推送；新建但未跟踪的文件不在补丁中，界面会提示数量，附件副本始终排除。

## 验证范围

未发送的文字草稿按项目或会话保存在本机，重开可继续编辑（最多保留近期 20 份，有总大小限制）。草稿附件和剪贴板图片不会随之恢复。上次关闭时，已经尝试发送但结果未确认的消息会在原会话中标注，不会自动重发。

`npm test` 验证 ACP 握手、Google 登录的协议分支、模型选项、按会话加入 MCP、流式回复/审批/停止，以及附件复制。离线交互预览已做浏览器测试。驱动校验用模拟 MCP 和 CLI 测试。上述引擎测试使用模拟 ACP 服务，**没有在真实 Mac 上完成 Google 登录、Cua Driver 授权或桌面动作**。另外用本地真实 Git 仓库测试了独立工作树和相对基线审阅；浏览器中测了快速切换、减少动态效果、断线的桌面桥接模拟和旧审阅请求乱序。此版不等于 Codex 全功能替代；后续差距见 `对照与后续.md`。
